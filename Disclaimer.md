## Notice Regarding Older Releases

Older RetroDisc releases are no longer distributed as ready-to-use packages.

For these releases, only the **source code** is retained and made available for reference and educational purposes. This allows users to inspect the implementation, understand how previous versions were built, and learn from the code.

If you wish to use an older version, you must **compile it yourself from the corresponding source code**.

The source code for older releases is available in the [RetroDisc-System Releases](https://github.com/JohnyCoolHD/RetroDisc-System/releases/).

> **Note:** Older releases do not include precompiled binaries, ready-to-use RetroDisc packages, or other prebuilt artifacts.
